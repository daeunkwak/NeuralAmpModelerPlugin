# BassNAM

A bass-focused fork of Neural Amp Modeler with Clean Blend and an optional LR4 crossover.

See [macOS local testing](LOCAL_TESTING.md) for building the standalone app,
installing VST3/AU plugins, and testing with a Scarlett interface.

Run automated DSP and state checks from the repository root:

```sh
bash NeuralAmpModeler/scripts/test-bass.sh
```
